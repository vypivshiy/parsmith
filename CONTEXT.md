# parsmith Domain Context

Canonical vocabulary for KDL schemas, compiler passes, codegen abstractions, and runtime contracts.

## Schema Types & DSL Constructs

**HTML schema**:
A KDL schema using regular (`item`), `list`, `table`, `dict`, or `flat` structs or `fn` declarations to extract values from an HTML DOM.
_Avoid_: REST schema, raw schema

**Raw schema**:
A KDL `(raw)struct` or `(raw)fn` that extracts values from plain text (`STRING` input) without an HTML parser.
_Avoid_: HTML schema

**REST schema**:
A KDL `(rest)struct` that describes HTTP requests, typed JSON response schemas, and discriminated error variants.
_Avoid_: HTML client, OpenAPI converter

**Pipeline**:
An ordered sequence of KDL operations transforming an input value into a typed output, with an optional terminal `fallback` literal.
_Avoid_: imperative IR block

**Cond (condition expression)**:
The recursive algebraic condition tree (`Cond::And`, `Cond::Or`, `Cond::Not`, `Cond::Atom(CondOp)`) and leaf operations (`CondOp`, `CondValue`) evaluated inside `filter`, `assert`, and `match` pipeline steps.
_Avoid_: `PredicateExpr`, `PredOp`, `PredValue`

**Portable regex subset**:
The cross-target regular expression dialect permitted in KDL schemas, supporting `(?x)` verbose multiline expansion into inline patterns while forbidding lookarounds (`(?=...)`, `(?!...)`, `(?<=...)`, `(?<!...)`) and named capture groups (`(?P<name>...)`, `(?<name>...)`), and requiring exactly one capturing group in pipeline `re` and `re-all` operations.
_Avoid_: full PCRE, `fancy-regex`

**Precomputed field**:
A named value derived from parser input by an `@init` pipeline during parser initialization and cached on the parser instance for `@name` references.
_Avoid_: constructor parameter, emitted output field

**Scalar define**:
A compile-time `UPPER_CASE` constant (`define KEY="value"`) substituted into operation arguments, `@request` templates, or subsequent scalar defines via `{{UPPER_NAME}}`.
_Avoid_: runtime parameter, environment variable

**Block define**:
A reusable `UPPER_CASE` KDL block (`define NAME { ... }`) spliced inline as pipeline steps inside a field or as field declarations inside a `json` schema.
_Avoid_: runtime function call, legacy `expr` operation

**Extension operation**:
A user-declared, explicitly typed target-code operation (`extension <Namespace> { <op> { sig <In> <Out>; ... } }`) invoked in pipelines with a mandatory `!` prefix (`!<Namespace>.<op>`), lazily emitting target imports and deduplicated helper functions only when referenced.
_Avoid_: built-in pipeline step, untyped inline code hook

**Typed placeholder**:
A lowercase runtime request parameter (`{{name[:type][[]][?][|style]}}`) inside an `@request` template that generates a typed method parameter and serializes scalars, optional values, and formatted arrays (`repeat`, `csv`, `bracket`, `pipe`, `space`) into URL paths, query strings, headers, or bodies.
_Avoid_: compile-time `{{UPPER_NAME}}` define interpolation

**Error discriminator (`@error[:<suffix>]`)**:
A `(rest)struct` rule matching an HTTP status code, required GJSON paths, and exact field values to project an error response into a typed `<Struct>Err<Status>[<Suffix>]` variant with safe fallthrough on projection failure.
_Avoid_: uncaught HTTP status exception

**Inline JSON schema**:
A nested `json` block declared inside an enclosing JSON field or `@value` directive, elevated by post-order compiler hoisting into a top-level `JsonDef` ahead of its parent.
_Avoid_: embedded runtime sub-schema

**Synthesized schema name**:
The deterministic PascalCase identifier generated by compiler hoisting for an anonymous inline JSON or `@value` block (`{Parent}{Field}Value`, `{DictName}Value`).
_Avoid_: mangled type name, random schema id

**GJSON path expression**:
A deterministic path expression (supporting object keys, escaped literal dots `\.`, non-negative array indices, array length `#`, and array projection `#.subpath`, without predicate filters) used in `from="..."`, `path="..."`, and `jsonify`.
_Avoid_: JSONPath, JMESPath

**JSON projector**:
A generated schema-specific allowlist function that validates container structure, extracts declared fields and GJSON paths, enforces `?` nullability and `@omitempty` rules, drops undeclared wire keys, and raises a schema-qualified decode error on contract mismatch.
_Avoid_: runtime schema descriptor table

## Compiler & Frontend Architecture

**KDL selector**:
A CSS3-like query expression (`name`, `(type)name`, `[key=val]`, `[N=val]`, combinators, `:root`, `:not`, `:has`, `:nth-child`) evaluated over an indexed KDL 2.0 document or subtree.
_Avoid_: XPath over KDL, string regex over KDL source

**SourceLoader**:
The compiler abstraction resolving imported `.kdl` modules by logical path from either the local filesystem or an in-memory virtual map (`MemorySourceMap`), enabling diskless compilation in web services and extensions.
_Avoid_: hardcoded filesystem reader

**Host SDK (`parsmith-py` / `parsmith-js`)**:
The native language bindings (`PyO3` `abi3` in `crates/parsmith-py` + `python/`; `napi-rs` Node-API C ABI in `crates/parsmith-js` + `js/`) exposing `check`, `generate`, `inspect_schema` / `inspectSchema`, `json_to_kdl` / `jsonToKdl`, and the 20 structured diagnostic, codegen, and `ModuleInfo` introspection classes over filesystem (`FsSourceLoader`) and virtual (`MemorySourceLoader`) sources.
_Avoid_: CLI stdout subprocess wrapper, partial AST binding

**Browser WASM bridge (`parsmith-wasm`)**:
The WebAssembly binding crate (`wasm32-unknown-unknown` / `wasm-bindgen`) exposing `parsmith` schema validation, multi-target code generation, `json-to-kdl` conversion, and AST selector extraction directly in browser runtimes without Python or server dependencies.
_Avoid_: Pyodide WebWorker bridge, remote compiler API

**Selector health check**:
Static extraction of CSS and XPath selector steps (`css`, `css-all`, `css-remove`, `xpath`, `xpath-all`, `xpath-remove`) and their terminal `fallback` clauses across a `struct` and its transitive `nested` references, evaluated against a sample HTML document to classify each selector as `ok`, `warn`, or `fail`.
_Avoid_: full parser execution, live site uptime check

**Schema validation**:
Successful 5-pass execution (`parsmith check`) verifying KDL 2.0 syntax, explicit imports, structural directives, selector/regex syntax, cross-target identifiers, and pipeline types without emitting or running target code.
_Avoid_: runtime health check, toolchain validation

**Toolchain validation**:
External execution of generated parsers through native ecosystem compilers, formatters, and runtimes (`pytest`, `mypy --strict`, `node`, `tsc --noEmit`, `go vet`, `go test`, `gofmt`, `cargo check`, `cargo test`, `rustfmt`, `elixir`, `mix`, `php -l`, `dotnet build`, `kotlinc` / `gradle test`).
_Avoid_: schema validation, snapshot test

**Cross-target parity**:
Identical extracted data structures produced across all target backends (`py-bs4`, `py-lxml`, `py-parsel`, `py-selectolax`, `js`, `ts`, `go`, `rust`, `elixir`, `php-native`, `php-dom-crawler`, `csharp`, `kotlin`) and model modes (`typeddict`, `dataclass`, `separate_runtime`) for the same KDL schema and input fixture.
_Avoid_: snapshot equivalence, string-level code comparison

**Compile-time CSS-to-XPath lowering**:
Deterministic translation of CSS3 selector ASTs into XPath 1.0 expressions inside `parsmith` for XPath-native DOM backends lacking built-in CSS3 engines (such as PHP's standard `ext-dom` `\DOMDocument` + `\DOMXPath` on PHP 8.1+), emitting `E002` when a selector uses CSS4 constructs not representable in XPath 1.0.
_Avoid_: runtime CSS parser library, PHP 8.4-only DOM requirement

**Structural HTML fixture**:
A compact, offline HTML document preserving the exact DOM hierarchy, class names, attribute quirks, and formatting noise of a real-world page or scraping sandbox while using controlled, minimal item payloads to test edge cases (`fallback`, nullable fields, noise filtering).
_Avoid_: live network target, unedited full-page dump

## Codegen & Runtime Contracts

**Algebraic AST**:
The immutable, strongly-typed Rust semantic representation of a compiled KDL module (`Module`, `StructDecl`, `JsonDef`, `FunctionDef`, `Pipeline`, `Cond`) free of parent back-pointers and synthetic hook marker nodes.
_Avoid_: untyped node list, statement-level imperative IR, `PredicateExpr`

**LanguageEmitter**:
The trait implemented by each target language backend (`PythonEmitter`, `JsTsEmitter`, `GoEmitter`, `RustEmitter`, `ElixirEmitter`, `PhpEmitter`, `CSharpEmitter`, `KotlinEmitter`) defining explicit module and struct lifecycle hooks (`on_module_start`, `emit_imports`, `emit_utilities`, `on_struct_start`, `emit_init`, `emit_start_parse`, `on_struct_end`, `on_module_end`) and AST node visitors.
_Avoid_: AST marker hook node (`CodeStartHook`, `CodeEndHook`, `StartParse`, `Utilities`)

**CodeWriter**:
The indentation-aware output buffer supporting `DryRun` mode (Pass 1, zero string output while populating `ModuleBuilder`) and `Emit` mode (Pass 2, rendering final formatted target code) via `writeln` / `wln!` and explicit `.indented(|w| ...)` blocks.
_Avoid_: manual indent string concatenation, `block(open, close, ...)` wrappers that hide closing delimiters at the top of a closure

**ModuleBuilder**:
An idempotent accumulator populated during Pass 1 (`DryRun`) that records parser-level imports (`require_import`) separately from unified `HelperDef` definitions and runtime-scoped imports (`require_std`, `require_std_with_imports`, `require_runtime`) before Pass 2 emits the file header or separated runtime module.
_Avoid_: single-pass forward-declaring emitter, conflating parser imports with separated runtime helper imports

**Runtime namespace (`rt`)**:
The unified naming convention for all compiler-synthesized runtime helpers, error classes, JSON projectors, table sentinels, DOM type aliases, and REST error matcher tables across targets (`rt_<snake>` / `Rt<Pascal>` / `RT_<UPPER>` in Python; exported `rt<Pascal>` / `Rt<Pascal>` / `RT_<UPPER>` in TypeScript and JavaScript; package-private `rt<Pascal>` and exported `Rt<Pascal>` in Go; `rt::*` module with `rt::RtError` and `RT_<UPPER>` in Rust; `Rt.*` module in Elixir; `Rt::*` class in PHP; `Rt.*` static class in C#; `Rt.*` object in Kotlin), while keeping the public HTTP transport and monadic REST result contracts (`HttpRequest`, `RawResponse`, `TransportError`, `SyncTransport`, `AsyncTransport`, `HttpTransport`, `via_*`, `With*`, `Ok`, `UnknownErr`, `TransportErr`, `DecodeErr`, `ErrMatcher`) unprefixed.
_Avoid_: `std_*` / `std*` prefix, legacy `ssc_*` / `ssc*` / `Ssc*` prefix, leading-underscore `_` module helpers

**DomSpelling**:
A backend sub-trait defining HTML-library-specific DOM query statements, XPath capability, and condition expressions for a target language (`Bs4Spelling`, `LxmlSpelling`, `ParselSpelling`, `SelectolaxSpelling`, and `PythonDom` in Python; `PhpNativeSpelling` and `PhpDomCrawlerSpelling` in PHP).
_Avoid_: HTTP transport adapter

**SyncTransport / AsyncTransport**:
The explicit object/protocol interface (`send(req: HttpRequest) -> RawResponse`) unifying third-party HTTP clients without compile-time `--http-client` branching or runtime duck-typing heuristics.
_Avoid_: HttpLibStrategy, duck-typed client heuristics

**HttpRequest / RawResponse**:
The normalized request (`method`, `url`, `headers`, `params`, `cookies`, `body`, `body_kind`, `extra`) and response (`status`, `headers`, `text`) data structures exchanged across `SyncTransport` / `AsyncTransport`.
_Avoid_: raw library response object

**TransportError**:
The single boundary exception raised by a transport adapter when its underlying HTTP client encounters a network/IO failure (`httpx.HTTPError`, `aiohttp.ClientError`, `requests.RequestException`, `urllib.error.URLError`), caught by the REST runtime to produce `TransportErr`.
_Avoid_: blanket `except Exception` heuristic

**DecodeErr**:
The dedicated REST error variant (`DecodeErr` in Python/TS/JS/PHP/C#/Kotlin, `*DecodeErr` in Go, `<Struct>Error::Decode` in Rust, `%Rt.DecodeErr{}` in Elixir) returned when an HTTP response arrives from the network (`2xx` or unmatched error) but fails JSON parsing or violates its declared `JsonDef` projector contract.
_Avoid_: uncaught projector exception in REST client, conflating decode failures into `UnknownErr`

**Transport factory (`via_*`)**:
A concise constructor helper (`via_httpx`, `via_httpx_async`, `via_requests`, `via_aiohttp`, `via_urllib`, `viaFetch`, `viaAxios`) returning a concrete `SyncTransport` / `AsyncTransport` adapter instance.
_Avoid_: `use_*` prefix (collides with React Hook lint rules in JS/TS)
