# Language-Agnostic `ModuleBuilder`, Hybrid Runtime Templates, and Direct REST Lowering

`ModuleBuilder` remains strictly language-agnostic—recording full import strings via fluent `.require_import(...)` calls without Python-specific `require_typing` state—while target emitters (such as `PythonEmitter::emit_imports`) merge and deduplicate `from <module> import ...` statements when rendering the file header. Large target runtime blocks (`http_transport`, `rest_core`, `json_project`) are stored as standalone target-language files loaded at compile time via `include_str!` while small 3–10 line helpers stay inline in Rust modules, and REST client emission lowers directly from shared domain methods on `Module`, `ResultAliasDef`, `PlaceholderSpec`, and `PlaceholderTemplate` rather than introducing a second intermediate REST IR layer.
