# Unified Runtime and Type Contracts Across Python `DomSpelling` Backends (`bs4`, `lxml`, `parsel`, `selectolax`)

All four Python `DomSpelling` implementations (`Bs4Spelling`, `LxmlSpelling`, `ParselSpelling`, `SelectolaxSpelling`) enforce a single runtime and `mypy --strict` contract rather than verbatim ports of legacy `ssc_codegen` templates. Specifically: (1) single-key `attr` (`attr "k"`) always resolves to `str` and raises `KeyError` when the attribute is absent so `fallback` blocks trigger identically across backends (in `bs4`, normalizing `Tag.__getitem__`'s `str | AttributeValueList` via `_v if isinstance(_v := tag[k], str) else ' '.join(_v)` rather than `get_attribute_list`, which silently returned `[None]` on missing attributes); (2) single-element `css` and `xpath` queries yield `T | None` without raising `IndexError` when immediately followed by `to-bool`, and `to-bool` on `DOCUMENT` checks `v is not None` (avoiding `lxml` `HtmlElement.__bool__`, which checks `len(children) > 0` and emits `FutureWarning`); (3) `SelectolaxSpelling` normalizes `str` and `LexborHTMLParser` inputs to their root `LexborNode` so `self._doc` has a uniform `LexborNode` type supporting `.attributes`, `.inner_html`, and `.decompose()`; and (4) `LxmlSpelling` and `ParselSpelling` remove elements via `drop_tree()` / `SelectorList.drop()` so trailing `tail` text is preserved.
