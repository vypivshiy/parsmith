# Explicit-Delimiter `CodeWriter`, Unified `ModuleBuilder`, and Shared Extension Lowering

`CodeWriter` standardizes formatted line emission on `writeln` and the zero-allocation `wln!(writer, ...)` macro while keeping block structure explicit via `.indented(|w| ...)` rather than `block(open, close, |w| ...)` wrappers—preserving top-to-bottom visual alignment of opening and closing delimiters (`{ ... }`, `do ... end`, `if / else`, `try / catch`) in Rust emitter code—and removes redundant or unused methods (`blank_line`, `writeln_fmt`, `write_raw_line`, `peek_var`, `var_counter`, `with_var_prefix`). `ModuleBuilder` unifies `StdHelperDef` and `RuntimeHelperDef` into `HelperDef`, separates zero-import registration (`require_std(name, code)`) from runtime-import registration (`require_std_with_imports(name, code, imports)`) so `-R / --separate-runtime` in Go and Python never leaks helper-only imports into parser files, short-circuits duplicate registrations before running `dedent_code_block`, returns zero-allocation `&IndexSet<String>` and key iterators from getters, and centralizes `StepOp::ExtensionCall` target resolution, helper registration, and template interpolation across all 8 language backends. Finally, `drive_single_pass` skips `emit_imports`, `emit_utilities`, `prologue`, and `epilogue` during Pass 1 (`DryRun`), executing header and utility rendering only in Pass 2 (`Emit`) after Pass 1 has populated `ModuleBuilder`.
