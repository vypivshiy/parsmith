# Browser Playground via Rust WASM (`parsmith-wasm`) and Native Browser DOM Execution

The interactive web playground (`playground/`) replaces the legacy Pyodide WebWorker runtime (~25 MB CDN/PyPI download of CPython, `lxml`, `beautifulsoup4`, and `ssc-codegen`) with a pure-Rust WebAssembly bridge (`crates/parsmith-wasm` via `wasm-bindgen`) paired with browser-native `DOMParser` and `XPathResult` execution. Because `parsmith` (`parsmith::kdl`) has zero C or OS dependencies and `JsTsEmitter` already emits standalone JavaScript targeting standard Web DOM APIs (`DOMParser`, `querySelectorAll`, `document.evaluate`), `parsmith-wasm` handles schema validation (`E000`–`E403`, `W011`–`W041`), 5-target code generation (`python`, `ts`, `js`, `go`, `rust`), `json_to_kdl` schema bootstrapping, and AST selector extraction in sub-millisecond time in-process, while live HTML parser execution (`<Struct>.parse()`) and selector health checks (`ok` / `warn` / `fail` across `css*` and `xpath*` steps with `fallback` awareness) run directly against the browser's native DOM engine with zero external network requests.
